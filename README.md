Over-engineered simple todo-list program. This is for learning purpose essentially.
A small program is often made with small code, here I did the opposite. Polymorphism, abstraction, display/logic seperation, unit testing, error handling, etc... It's absolutely overkill, but I found that it was a good way of practicing all of these aspects of programming clean and robust code in Rust.
This repository is here so I don't forget how I did it and I might add some new unnecessary features from time to time.
